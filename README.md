# quicview
QUIC log analysis tooling

Tested on Ubuntu 22.04.

From FastAPI docs:
```
    python3 -m venv .venv
    source .venv/bin/activate
    python3 -m pip install --upgrade pip
    echo "*" > .venv/.gitignore
    pip install -r requirements.txt
    fastapi dev main.py
```
